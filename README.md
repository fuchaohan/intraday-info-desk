# 盘中信息台

一个基于原生 HTML / CSS / JavaScript 的 A 股盘中信息台页面，当前聚焦板块资金流、累计净流入曲线与近 5 分钟异动监测。

## 功能概览

- 板块 / 概念主力资金净流入累计曲线
- 累计净流入榜与近 5 分钟异动榜
- 概念 / 行业切换
- 手动屏蔽板块并持久化到浏览器本地

## 使用方式

直接打开 `index.html` 即可运行。
